# Always Ask for Review

Before making any modifications to files, executing potentially modifying commands, or committing changes to the codebase, you MUST:
1. Propose the intended changes to the user.
2. Clearly explain what files will be modified and how.
3. Explicitly ask the user for a review and approval.
4. Wait for the user's explicit approval before proceeding with the actual changes.
